# Screenshots

This folder contains screenshots from my Databricks Community Edition workspace and PySpark learning exercises.

The screenshots demonstrate:

- Data ingestion and file reading
- Manual schema creation using StructType
- Handling corrupt records
- DataFrame transformations
- Aggregations and Group By operations
- Joins and Window Functions
- Partitioning and Bucketing examples
- Databricks notebook execution and outputs

These images are included to provide visual evidence of the implementation and results of the examples available in this repository.
